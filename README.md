# CopyBoard Funnel Launch

Build the first 5 sections of a premium, high-conversion FUNNEL PAGE (not

a multi-page company website) for "CopyBoard" — a done-for-you, unlimited

content creation subscription for creators and brands: unlimited graphic

design, video editing, podcast editing, short-form and long-form content,

one flat monthly fee, real human creators (never AI), fast turnaround,

cancel anytime. Single-scroll funnel, every section builds toward one

action: clicking "Chat With Us." No multi-page navigation, no About page,

no course/curriculum language ("modules," "lessons," "enroll").

Build ONLY these 7 sections for now, in this order: Hero/VSL, Growth

Stats, What's Included + Video Grid, Services, Trusted By, Pricing,

Process. More sections will be added in a follow-up prompt — build these

7 to a fully finished, polished standard as if the page ends at Process

for now.

============================================================

COLOR SYSTEM — STRICT, NO EXCEPTIONS

============================================================

- Ink Black #0D0D0C — background for every section

- Warm Charcoal #171614 — card/surface background within sections

- Signal Yellow #FFD400 — the ONE accent color, identical everywhere:

  every button, highlight, icon accent, glow, border, stat number,

  sticker badge, star/diamond accent

No white/light backgrounds anywhere. No red, blue, green, purple. Every

card/button/box uses soft rounded corners — no sharp square corners

anywhere on the page.

============================================================

CTA RULE

============================================================

Every CTA says "Chat With Us" (never "Book a Call"), styled as if it

opens a live chat widget. Solid yellow fill, black text, small custom SVG

arrow icon after the label that nudges 4-6px on hover with smooth

transition.
